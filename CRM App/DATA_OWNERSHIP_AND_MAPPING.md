# VUDFIT Data Ownership & Mapping Guide (`DATA_OWNERSHIP_AND_MAPPING.md`)

This document establishes the **Single Source of Truth (SSOT)** rules and data ownership boundaries for each business record across all four applications to eliminate data collisions, race conditions, and conflicting financial/stock figures.

---

## 1. Non-Negotiable Data Ownership Matrix

| Data Entity | Authoritative Owner System | Read-Only Replicated Systems | Sync Trigger / Direction | Conflict Resolution Strategy |
| :--- | :--- | :--- | :--- | :--- |
| **Customer Master** | **CRM App** | Quotation App, Invoicing | CRM &rarr; Quotation (On Lead Qualification) | CRM always overwrites customer profile updates |
| **Quotation & Pricing** | **Quotation App** | CRM App (as summary offer) | Quotation &rarr; CRM (On Client Quotation Approval) | Quotation App owns versioning (`v1`, `v2`). CRM cannot edit quote math |
| **Project / Sales Order** | **CRM App** | PO App, Inventory App | CRM &rarr; All Systems (On Order Release Gate 6) | Job ID `VDF-YYYY-XXXX` is immutable once frozen |
| **Supplier POs** | **PO App** | CRM App (as PO numbers) | PO App &rarr; CRM (On PO Authorization) | PO App controls vendor terms and pricing |
| **Stock & Item Master** | **Inventory App** | CRM App, PO App | Inventory &rarr; CRM (On Material Selection / Goods Receipt) | Inventory App owns stock balances and item codes |

## 2. Business Identifier Reconciliation Rules

```
+-----------------------------------------------------------------------------------+
|                        THE JOB NUMBER IS THE BACKBONE                             |
|                               (VDF-2026-XXXX)                                     |
+------------------------------------+----------------------------------------------+
                                     |
    +--------------------------------+--------------------------------+
    |                                |                                |
    v                                v                                v
[Quotation App]                   [PO App]                    [Inventory App]
External Ref: QTN-2026-089      External Ref: PO-2026-402    External Ref: SKU-HDHMR-18
Linked to: VDF-2026-0001        Linked to: VDF-2026-0001     Issued to: VDF-2026-0001
```

### Reconciliation Rules:
1. **Job ID (`VDF-YYYY-XXXX`)**: Standard format generated by CRM upon client order confirmation. Every quotation, purchase order, material issue slip, snag, and invoice MUST carry this Job ID as a secondary indexing key.
2. **Customer ID (`CUST-YYYY-XXXX`)**: Generated by CRM when a lead is qualified (Gate 1). The Quotation system imports this ID to attach pricing offers to the verified customer.
3. **Quotation ID (`QTN-YYYY-XXXX`)**: Generated by Quotation App. Stored in CRM as `external_quotation_id`. When a quotation is marked "Client Approved" in the Quotation system, a webhook notifies the CRM to auto-populate the contract value and move the job to `08 Final Design Approval`.
4. **PO Number (`PO-YYYY-XXXX`)**: Generated by PO App. Stored in CRM materials table as `external_po_ref`.
5. **Item Code (`SKU-XXXX-YY`)**: Managed by Inventory App. Stored in CRM materials table as `external_inventory_item_code`.

## 3. Conflict Handling & Verification Requirements

- **No Silent Conflicts**: No system is permitted to silently update financial figures or stock quantities without passing an authenticated API request with a unique transaction payload token.
- **Audit Log Verification**: Every cross-system synchronization event is logged into `integration_audit_log` with `event_type`, `source_system`, `target_system`, `entity_id`, `status`, and `payload`.
